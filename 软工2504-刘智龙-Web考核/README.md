## 页面主要功能

1. 固定顶部导航，滚动后切换为毛玻璃背景。
2. 移动端汉堡菜单。
3. 深色 / 浅色主题切换，并使用 localStorage 保存主题选择。
4. 技能区分组 Tab 切换。
5. 学习目标折叠展开，使用 max-height 过渡动画。
6. QQ 号点击复制，并显示 Toast 提示。
7. 页面顶部滚动进度条。
8. 使用 IntersectionObserver 实现导航高亮。
9. 使用 IntersectionObserver 实现元素进入视口的淡入上滑和交错动画。
10. 技能进度条进入视口后填充。
11. 滚动超过一屏后显示回到顶部按钮。
12. 终端窗口使用 requestAnimationFrame 逐行打字。
