03 / FUTURE PLAN

未来规划

本科就业方向已经明确，接下来重点是持续学习和积累真实项目经验。

目标方向

本科就业 · Java 后端开发

以 Java 后端为主线，通过课程学习、完整项目、算法训练和实习逐步建立就业能力。

为什么选择这个方向

  • 我更倾向于早点进入社会积累实战经验，不想继续读研。
  • 通过 Java 基础和两次建模比赛的编程经历，我确认自己对后端开发有兴趣。
  • 后端方向岗位需求稳定，也能把我目前学习的 Java 真正用起来。

为什么不考研

不是觉得考研不好，而是我判断自己更适合在真实项目中成长。 把时间投在实习和项目上，对我个人来说收益更大。
